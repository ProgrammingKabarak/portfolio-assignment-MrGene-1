## Project Description

A responsive personal portfolio website built with HTML5, CSS3, and vanilla
JavaScript. It showcases my profile, technical skills, projects, resume, and
contact information as the capstone project for the Markup and Scripting
course.

## Technologies Used

- HTML5 (semantic elements, forms, meta tags)
- CSS3 (Flexbox, Grid, custom properties, transitions, animations, media queries)
- Vanilla JavaScript (no frameworks or libraries)

## Features Implemented

- Responsive navigation menu with mobile toggle
- Dark / light mode toggle (persisted via `localStorage`)
- Dynamic greeting based on time of day
- Scroll-to-top button
- Animated skill bars triggered on scroll (Intersection Observer)
- Scroll reveal animations for sections and cards
- Contact form with custom JavaScript validation and inline error messages
- Dynamically generated copyright year in the footer
- Fully responsive layout for mobile, tablet, laptop, and desktop
- Accessible markup: semantic HTML, alt text, form labels, visible focus states
